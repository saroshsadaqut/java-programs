# Java Mini Projects

This repository contains three simple Java programs:

1. **Guess the Number Game**
2. **Rock Paper Scissors Game**
3. **To-Do List Application**

## 1. Guess the Number Game

A simple number guessing game where the computer generates a random number and the player tries to guess it.

### Features:
- Generates a random number between 1 and 100
- Provides hints (too high/too low) after each guess
- Tracks the number of attempts
- Option to play again
  
## 2. Rock Paper Scissors Game
A classic Rock-Paper-Scissors game played against the computer.

### Features:
- Player chooses between Rock, Paper, or Scissors
- Computer makes a random selection
- Determines the winner based on game rules
- Keeps score across multiple rounds
- Option to play again

## 3. To-Do List Application
A simple console-based to-do list manager that persists tasks to a file.

### Features:
- View all tasks
- Add new tasks
- Remove completed tasks
- Persistent storage in tasks.txt file
- Simple and intuitive interface

### File Storage:
Tasks are stored in tasks.txt in the same directory as the program.

## How to Run:
```bash
javac ProgramName.java
java ProgramName
```
## Requirements
Java JDK 8 or later
